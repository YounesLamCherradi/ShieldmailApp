# 🛡️ Shieldmail
### Real-Time Spam and Malicious Link Detection

Shieldmail is an intelligent web application designed to detect spam content and malicious/phishing links in emails in real time. It provides accurate classification, detailed analysis, and clear insights to help users maintain online security and avoid harmful messages.

**Academic Team Project** **Institution**: ITMO University, St. Petersburg, Russia  
**Course**: Web Software Development  
**Lead Contributor**: Lamhamedi-Cherradi Younes ([younes@lamhamedicherradi.com](mailto:younes@lamhamedicherradi.com))

---

## 🚀 Key Features

* **Real-Time Classification**: Swiftly catches and filters spam content before it reaches the user.
* **Malicious Link Detection**: Hunts down phishing URLs to provide a protective shield.
* **Sentiment Analysis**: Harnesses emoticons and text patterns for deeper content insight.
* **Multilingual Support**: Breaking language barriers to ensure security across different regions.

## 🛠️ Technology Stack

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Backend** | Flask (Python) | Nimble web framework for core logic and scalability. |
| **Frontend** | JS & AJAX | For interactive interfaces and real-time updates without reloads. |
| **Database** | MongoDB | Flexible NoSQL storage for fast data management. |
| **Web Server** | Nginx | High-performance reverse proxy and protective charm. |
| **WSGI** | Gunicorn | Production-grade server to execute the Flask application. |
